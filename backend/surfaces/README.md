`tiles.bin` contains four 128 x 128, row-major grayscale tiles extracted from
Roblox Studio's `PlatformContent/pc/textures/studs.dds`. The tiles start at
atlas rows 0, 512, 1024 and 1536 and contain Studs, Weld/Glue, Inlet and Universal,
respectively. Each tile spans two studs in both directions. The red channel
stores surface shading, with 128 as neutral.
